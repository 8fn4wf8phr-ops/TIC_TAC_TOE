# Tic-Tac-Toe

A classic Tic-Tac-Toe game — Two Players and Vs. Computer modes, with an unbeatable AI opponent.

**Live:** https://tic-tac-toe-eight-rho-82.vercel.app
**GitHub:** https://github.com/8fn4wf8phr-ops/TIC_TAC_TOE

## Features

- Two Players mode, or Vs. Computer with an unbeatable minimax AI
- Choose to play as X (go first) or O (go second) against the computer
- Winning line highlight, draw detection
- Scoreboard (X / O / draws) that persists across visits
- Dark mode toggle, remembers your preference and respects your system setting by default
- Restart or change mode without reloading the page

## Tech Stack

- HTML5
- CSS3 (custom properties for theming, light/dark palettes)
- Vanilla JavaScript — no frameworks, no build step, no dependencies

## Getting Started

No build step required. Open `index.html` directly in a browser, or serve the folder locally:

```
python3 -m http.server 8083
```

Then visit `http://localhost:8083`.
